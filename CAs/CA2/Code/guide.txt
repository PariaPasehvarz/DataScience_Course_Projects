Spark executor CPU/MEM

sudo nano /opt/jmx/jmx_config.yaml
write this there:
startDelaySeconds: 0
lowercaseOutputName: true
lowercaseOutputLabelNames: true
rules:
  - pattern: 'java.lang:type=OperatingSystem'
    name: jvm_cpu
    type: GAUGE
    attr:
      ProcessCpuLoad: process_cpu_load
      SystemCpuLoad: system_cpu_load
      AvailableProcessors: available_processors
      SystemLoadAverage: system_load_average

  - pattern: 'java.lang:type=Memory'
    name: jvm_memory
    type: GAUGE
    attr:
      HeapMemoryUsage.used: heap_used
      HeapMemoryUsage.committed: heap_committed
      HeapMemoryUsage.max: heap_max
      NonHeapMemoryUsage.used: nonheap_used
      NonHeapMemoryUsage.committed: nonheap_committed
      NonHeapMemoryUsage.max: nonheap_max

1. Run zookeeper in one terminal
2. Run Kafka in another terrminal
3. Run Producer in another terminal
4. Run Consumer in another terminal
5. Run streaming app (or anything you want) in another terminal
   use this command:
   spark-submit \
  --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.5 \
  --conf "spark.executor.extraJavaOptions=-javaagent:/opt/jmx/jmx_prometheus_javaagent-0.18.0.jar=8081:/opt/jmx/jmx_config.yaml" \
  --conf "spark.driver.extraJavaOptions=-javaagent:/opt/jmx/jmx_prometheus_javaagent-0.18.0.jar=8080:/opt/jmx/jmx_config.yaml" \

Go to graph section: enter: 
Shows live heap memory used by the JVM (in bytes) -> jvm_memory_bytes_used{area="heap"}
Shows how full your heap memory is -> 100 * jvm_memory_bytes_used{area="heap"} / jvm_memory_bytes_max{area="heap"}
Current Non-Heap Memory Used(Tracks memory for class metadata, code caches, etc.) -> jvm_memory_bytes_used{area="nonheap"}
Process Resident Memory (RAM used by executor) -> process_resident_memory_bytes
Total Committed Memory(Memory reserved by JVM (not necessarily used)) -> jvm_memory_bytes_committed{area="heap"}

JVM garbage collection time

What should be installed?

sudo mkdir -p /opt/jmx
wget https://repo1.maven.org/maven2/io/prometheus/jmx/jmx_prometheus_javaagent/0.18.0/jmx_prometheus_javaagent-0.18.0.jar
sudo nano /opt/jmx/jmx_config.yaml
write this there:
startDelaySeconds: 0
lowercaseOutputName: true
lowercaseOutputLabelNames: true
rules:
  - pattern: 'java.lang:type=GarbageCollector,name=(.*)'
    name: jvm_gc_time_seconds
    type: COUNTER
    attr:
      CollectionTime: collection_time
      CollectionCount: collection_count
    labels:
      gc_collector: "$1"
      
1. Run zookeeper in one terminal
2. Run Kafka in another terrminal
3. Run Producer in another terminal
4. Run Consumer in another terminal
5. Run streaming app (or anything you want) in another terminal
   use this command:
   spark-submit \
  --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.5 \
  --conf "spark.driver.extraJavaOptions=-javaagent:/opt/jmx/jmx_prometheus_javaagent-0.18.0.jar=8080:/opt/jmx/jmx_config.yaml" \
  --conf "spark.executor.extraJavaOptions=-javaagent:/opt/jmx/jmx_prometheus_javaagent-0.18.0.jar=8081:/opt/jmx/jmx_config.yaml" \
  streaming_app.py
6. you can see jvm_gc_collection_seconds summary here:
http://localhost:8080/metrics

7. if you want to monitor it in Prometheus GUI too:
cd /usr/bin
sudo ./prometheus --config.file=/home/paria/Documents/UT/DataScience/CA2/prometheus.yml
Then go to:
http://localhost:9090
Go to graph section: enter: jvm_gc_collection_seconds_sum / jvm_gc_collection_seconds_count
This will show:
The average time (in seconds) the JVM spent per garbage collection event since the application started.
